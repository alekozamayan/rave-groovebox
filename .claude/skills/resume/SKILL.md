---
name: resume
description: Pick up Rave Groovebox work where the last session left off. Use at the start of a session or when the user says "continue", "where were we" or "what's next".
---

1. Read `docs/STATUS.md` (current state, decisions, environment notes, roadmap).
2. `git status`, `git log --oneline -10`, and check open PRs / the latest CI run if GitHub tools are available.
3. Summarize in a few lines: released version, work in progress, the next roadmap item. Ask only if the next step is genuinely unclear.
4. Before ending the session, update `docs/STATUS.md` (state, decisions, new gotchas, roadmap).
